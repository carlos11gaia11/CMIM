Limite importante

Um arquivo HTML local não consegue consultar de maneira confiável todos os sites competitivos, devido a CORS, autenticação, políticas de uso e ausência de APIs públicas. Para estatísticas reais, o próximo passo é conectar um backend com fontes autorizadas, cache e identificadores de patch, elo e torneio.

Importar evidências estatísticas autorizadas

JSON · Dados locais

Carregue um JSON obtido de fonte autorizada ou de partidas próprias. O painel valida matchup, função, amostra, patch e taxas de vitória e mostra a origem. Nenhum site externo é consultado automaticamente.

Formato de importação e validação
{
  "source": "Partidas próprias CMIM",
  "patch": "26.22",
  "region": "BR",
  "rank": "Diamante+",
  "records": [
    {"champion":"Gwen","opponent":"Malphite","role":"TOP","games":300,"wins":165}
  ]
}

O exemplo contém valores demonstrativos; não representa resultados observados.
